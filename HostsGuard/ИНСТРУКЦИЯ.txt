HostsGuard — автопроверка обходных IP в hosts

УСТАНОВКА / ОБНОВЛЕНИЕ
1. Распакуй архив куда угодно.
2. Запусти УСТАНОВИТЬ.cmd и согласись на запрос администратора.
3. Скрипт сам скопирует всё в C:\HostsGuard (твой config.txt, журнал и найденные IP не трогает),
   создаст задачу в Планировщике (при включении ПК и каждые 60 минут, от SYSTEM, без окон)
   и сразу сделает проверку.

ЧТО ДЕЛАЕТ
- Раз в час проверяет текущий IP каждой нейронки. Работает — не трогает (Google не любит смену IP).
- Если IP умер или Google кидает на проверку «unusual traffic» — проверяет ВСЕ IP разом (параллельно,
  несколько секунд) и ставит самый быстрый рабочий.
- Раз в 12 часов сам скачивает свежий список IP GeoHide с GitHub (ips_source.txt).
- Если не работает ни один IP из списков — сам спрашивает у DNS-сервисов обхода (GeoHide, Comss, DNS-AI,
  KeyOneDay), какой IP они дают сейчас. Такой IP ставится, только если доказано, что это обход:
  скрипт через него спрашивает у сайта, с какого адреса тот видит запрос. Видит твой адрес или Россию —
  IP отбрасывается. Доказанные складывает в ips_proxy.txt.
- Ответа от каждого IP ждёт до 30 секунд: медленный, но живой IP мёртвым не считается.
- Если не отвечает вообще никто — наугад ничего не ставит: возвращает последний IP, который у этой нейронки
  реально работал (помнит в last_good.txt), и пишет в журнал причину по каждому IP
  (молчит / соединение оборвано / чужой сертификат) и есть ли вообще интернет на ПК.
- Перед каждой правкой кладёт копию hosts в C:\HostsGuard\backups. Журнал — C:\HostsGuard\log.txt.

КНОПКИ (всё в C:\HostsGuard)
- CLAUDE.cmd, CHATGPT.cmd, GEMINI.cmd, AI_STUDIO.cmd — жми, когда эта нейронка не открывается:
  проверит все IP только для неё и поставит ДРУГОЙ рабочий IP. Остальные строки hosts не трогает.
  Не помогло — жми ещё раз, поставит следующий.
- ВЕРНУТЬ_КОПИЮ.cmd — если что-то сломалось: возвращает последнюю копию hosts и выключает
  фоновую проверку (включить обратно - УСТАНОВИТЬ.cmd).
- ПРОВЕРИТЬ_СЕЙЧАС.cmd — обычная проверка всех.
- САМЫЙ_БЫСТРЫЙ.cmd — самый быстрый IP для всех, даже если текущий работает.
- УДАЛИТЬ.cmd — убирает задачу из Планировщика и свой блок из hosts (остальные строки hosts не трогает,
  копию прежнего hosts кладёт в backups). Папку не трогает.
- После смены IP закрой браузер полностью и открой заново.

НОВЫЙ АРТЕФАКТ CLAUDE НЕ ГРУЗИТСЯ
1. Скопируй UUID из адреса в ошибке (xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.frame.claudeusercontent.com).
2. Допиши его отдельной строкой в config.txt, в группу [group Claude-artifacts].
3. Запусти CLAUDE.cmd.

КАСПЕРСКИЙ
Он уже один раз сбрасывал hosts к стандартному. Чтобы не повторялось, добавь в исключения
Касперского файл C:\Windows\System32\drivers\etc\hosts и папку C:\HostsGuard.

ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ
Копии hosts лежат в C:\HostsGuard\backups. Любую можно вернуть на место:
C:\Windows\System32\drivers\etc\hosts
